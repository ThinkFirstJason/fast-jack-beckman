# "Fast Jack" Beckman — Website Redesign Concept

An unofficial redesign concept for [gofastjack.com](https://gofastjack.com/), the site of 2012 NHRA Funny Car World Champion Jack Beckman (PEAK Chevrolet SS, John Force Racing).

**Live preview:** https://thinkfirstjason.github.io/fast-jack-beckman/

- Single static page (`index.html`), no build step
- Blue / white / black palette built around the PEAK sponsorship
- Keeps every navigation tab from the current site; sub-pages link to the existing gofastjack.com pages
- Career stats, crown-jewel wins, 2026 season, upcoming races and recent results (as of October 2026)

Not affiliated with Jack Beckman, John Force Racing, PEAK / Old World Industries, or NHRA. Photos and logos belong to their respective owners.
